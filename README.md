# TT NGFW — Device Overview

Интерактивный frontend-прототип экрана обзора устройства из Figma.

## Запуск

Требуется Node.js 22 или новее и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite.

```bash
npm run build
npm run preview
```

Сборка размещается в `dist/client`. Шаблон также сохраняет Worker и метаданные для возможного размещения через Sites; проект не опубликован.

## Технологии

React 19, Vite 6, Chart.js 4, обычный CSS, локальные шрифты Inter.

## Что работает

- Поиск устройств, пустое состояние и сброс поиска.
- Фильтрация по типу устройства и сортировка по имени.
- Выбор устройства с обновлением демонстрационных показателей.
- Добавление устройства в текущую сессию с проверкой имени.
- Сворачивание основной и внутренней навигации, групп меню и списка устройств.
- Разворачивание обзора и возврат к обычному виду.
- Переключение показателя и видимости годовых рядов линейного графика.
- Подсказки столбчатых диаграмм и просмотр распределения по регионам.
- Адаптивная компоновка, клавиатурный фокус и закрытие диалогов по Escape.

## Границы прототипа

Данные демонстрационные. Подключения к оборудованию, backend/API, аутентификации и постоянного хранения нет. Добавленные устройства исчезают после перезагрузки. Основное меню вне раздела Devices показано как часть исходного макета. Соседние разделы внутренней навигации открывают краткую информацию, а не полноценные экраны конфигурации.

Начальные значения карточек повторяют Figma. Столбцы построены по визуальным пропорциям макета; значения подсказок и данные альтернативных состояний иллюстративные. Начальный линейный график и кольца используют оригинальные SVG из Figma. При переключении показателей линейный график строит Chart.js.

## Файлы

- `src/App.jsx` — оболочка, устройства, фильтры, навигация и диалоги.
- `src/Charts.jsx` — графики и их интерактивные состояния.
- `src/styles.css` — стили и адаптивные правила.
- `public/assets/` — оригинальные иконки, логотип, аватар и графика из Figma.
- `docs/figma-source.md` — исходный макет и сопоставление компонентов.
- `design-qa.md` — результаты визуальной и функциональной проверки.
- `qa-responsive.html` — локальный стенд проверки ширины 390 px.

## Источник

[Обзор устройства в Figma](https://www.figma.com/design/NHKrmsGZt6Qobta2FpLUM2/?node-id=40013110-221259).

Макет 1920 × 1200. Для визуального сравнения `/?reference` показывает тот же холст в масштабе 2/3. Обычный маршрут `/` адаптируется к окну.

Оригинальные ресурсы экспортированы из предоставленного пользователем файла без изменения самого дизайна. Права на исходный дизайн и бренд остаются у их владельцев. Лицензии зависимостей определяются соответствующими пакетами.
